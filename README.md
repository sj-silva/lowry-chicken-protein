# lowry-chicken-protein

Cuantificación de proteínas na carne de polo utilizando o método de Lowry (Folin-Ciocalteu).

**Autor:** Aman Santana Da Silva  
**Centro:** IES Lucus Augusti

## Tecnoloxías

- Node.js + Express
- EJS (templates)
- JSON (datos experimentais)
- Chart.js (gráficos)

## Como executar

\`\`\`bash
npm install
npm run dev     # con nodemon
# ou
npm start       # produción
\`\`\`

Accede a http://localhost:3000
